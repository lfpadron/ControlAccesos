Gestión de pantallas de turnos

Guía para crear clústers, registrar pantallas públicas y configurar los colores con los que se muestran los turnos llamados.

Resumen rápido

Dirigido a Administradores de sistema y administradores de negocio.
Resultado Una pantalla activa que muestra los turnos de uno o varios clústers.
Menús clave Instituciones > Clústers y Operación > Pantallas de turnos.

Las pantallas de turnos se configuran en dos partes. Primero se crea el clúster, que agrupa el área del piso donde se mostrarán los llamados. Después se registra la pantalla, se asocia al clúster y se ajustan sus colores, tamaños y tiempos de despliegue.

Antes de empezar: deben existir la institución, el complejo y el piso donde estará la pantalla. Si los turnos saldrán de consultorios específicos, esos consultorios también deben estar asociados al clúster correspondiente.

Dónde Entrar

Actividad Menú Qué se configura
Dar de alta o editar un clúster Instituciones > Clústers Complejo, piso, nombre, descripción y estado activo.
Registrar o editar una pantalla Operación > Pantallas de turnos Dispositivo, nombre, clústers asignados, token, estado, colores, tamaños y tiempos.
Revisar que llegan turnos a una pantalla Operación > Pantallas de turnos Tabla de pantallas y sección Despliegue actual.

Alta de un Clúster

Use el clúster para indicar qué grupo de consultorios o área del piso alimentará una pantalla de turnos. Por ejemplo: Lobby planta baja, Piso 2 norte o Laboratorio.

  1. Ingrese a la web administrativa de Control de acceso.
  2. En el menú lateral, abra Instituciones > Clústers.
  3. En el formulario Crear clúster, seleccione la Institución.
  4. Seleccione el Complejo. El sistema filtrará los pisos de ese complejo.
  5. Seleccione el Piso donde se usará el clúster.
  6. Capture el Nombre. Use un nombre corto y fácil de reconocer por operación.
  7. Capture una Descripción si ayuda a identificar el alcance del clúster.
  8. Deje marcada la opción Activo.
  9. Presione Guardar.
Importante: si un consultorio no está asociado a un clúster con pantalla activa, el sistema puede impedir o rechazar el llamado de turno hacia pantalla. Revise la asociación del consultorio cuando un turno no aparece.

Alta de una Pantalla

Una pantalla representa el dispositivo público que abrirá la URL de display y mostrará los turnos llamados. Puede asignarse a uno o varios clústers del mismo complejo y piso.

  1. Abra Operación > Pantallas de turnos.
  2. En Crear pantalla, seleccione Institución, Complejo y Piso.
  3. En el campo Clúster, busque el clúster creado y presione Agregar. Debe quedar visible como etiqueta debajo del campo.
  4. Capture el Dispositivo. Este código identifica la pantalla y forma parte de su URL pública. Use un valor único, por ejemplo display-lobby-pb.
  5. Capture el Nombre, por ejemplo Pantalla lobby planta baja.
  6. Revise la URL de pantalla. El sistema la genera automáticamente con el código de dispositivo.
  7. Capture una Descripción si necesita documentar la ubicación física o uso de la pantalla.
  8. Opcionalmente capture un Token. Si se usa token, la pantalla deberá abrirse con ese token para consultar turnos.
  9. Configure Polling, que indica cada cuántos segundos la pantalla consulta nuevos turnos. El valor permitido va de 2 a 10 segundos.
  10. Deje marcada la opción Activa para que pueda recibir llamados.
  11. Presione Guardar.

Después de guardar, la pantalla aparece en la tabla con columnas de Dispositivo, Nombre, Clústers, Polling, Estado y Acciones. Desde ahí puede editarla, desactivarla o volver a activarla.

Configuración de Colores y Visualización

La sección Detalle visual define cómo se verá la pantalla pública. Use colores con buen contraste para que los pacientes puedan leer el turno a distancia.

Campo Uso Valor sugerido
Color de fondo Color principal detrás de los turnos. black para alto contraste.
Color de letra Color del texto general de la pantalla. white sobre fondo oscuro.
Color turno nuevo Color usado para resaltar el turno recién llamado. yellow para hacerlo visible rápidamente.
Color turno normal Color usado cuando el turno ya no está resaltado, pero sigue visible. white para mantener lectura clara.
Tamaño turno nuevo Tamaño de letra del turno recién llamado. Rango permitido: 24 a 220. 96 para pantallas de sala.
Tamaño turno normal Tamaño de letra para turnos ya visibles. Rango permitido: 18 a 160. 64 para mantener varios turnos legibles.
Segundos resaltado Tiempo en que un turno permanece marcado como nuevo. Rango permitido: 5 a 120. 25 segundos.
Segundos visible Tiempo total en que el turno permanece visible. Rango permitido: 30 a 3600. 300 segundos.
Máximo de turnos Cantidad máxima de turnos que se muestran al mismo tiempo. Rango permitido: 1 a 50. 10 turnos.
Vista previa: el formulario muestra una muestra visual con el nombre de la pantalla y un turno de ejemplo. Úsela para validar contraste antes de guardar.

Ejemplo Práctico

Objetivo

Configurar una pantalla para el lobby de planta baja de Clínicas Alfa, donde se mostrarán los turnos llamados desde los consultorios del área de recepción principal.

1. Crear el clúster

  1. Ir a Instituciones > Clústers.
  2. Seleccionar Institución: Clínicas Alfa.
  3. Seleccionar Complejo: Torre Central.
  4. Seleccionar Piso: Planta baja.
  5. Capturar Nombre: Lobby planta baja.
  6. Capturar Descripción: Turnos visibles para recepción principal y consultorios de planta baja.
  7. Confirmar que Activo esté marcado y presionar Guardar.

2. Registrar la pantalla

  1. Ir a Operación > Pantallas de turnos.
  2. Seleccionar Institución: Clínicas Alfa.
  3. Seleccionar Complejo: Torre Central.
  4. Seleccionar Piso: Planta baja.
  5. En Clúster, buscar Lobby planta baja y presionar Agregar.
  6. Capturar Dispositivo: display-lobby-pb.
  7. Capturar Nombre: Pantalla lobby PB.
  8. Opcionalmente capturar un token, por ejemplo LobbyPB2026, si se quiere proteger la consulta pública.
  9. Dejar Polling: 5 segundos y Activa marcado.

3. Configurar colores

Color de fondo black
Color de letra white
Color turno nuevo yellow
Color turno normal white
Tamaño turno nuevo 96
Tamaño turno normal 64
Segundos resaltado 25
Segundos visible 300
Máximo de turnos 10

Presionar Guardar. La pantalla quedará disponible en una URL similar a /display/display-lobby-pb. Si se configuró token, la URL incluirá el parámetro correspondiente.

Verificación Final

  • El clúster aparece como Activo en Instituciones > Clústers.
  • La pantalla aparece como Activa en Operación > Pantallas de turnos.
  • La pantalla tiene al menos un clúster agregado.
  • La URL de pantalla abre correctamente desde el botón Abrir.
  • La vista previa tiene contraste suficiente entre fondo, texto y turno nuevo.
  • Al llamar un turno desde un consultorio asociado al clúster, el turno aparece en la pantalla.
Si no aparece el turno: confirme que la pantalla está activa, que el clúster asignado es el correcto, que el consultorio pertenece a ese clúster y que el token usado en la URL coincide con el configurado para la pantalla.
