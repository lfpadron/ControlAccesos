Gestión de kioskos

Guía para crear puntos de acceso, registrar kioskos de autoservicio y configurar su presentación visual.

Resumen Rápido

Dirigido a Administradores de sistema y administradores de negocio.
Resultado Un kiosko activo ligado a un punto de acceso físico.
Menú clave Operación > Kioskos.

El kiosko permite que el paciente registre su llegada desde una pantalla de autoservicio. En la app, la gestión se divide en dos partes: primero se crea el punto de acceso, que representa la ubicación física; después se registra el kiosko, que representa el dispositivo instalado en ese punto.

Antes de empezar: deben existir la institución, el complejo y el piso donde se instalará el kiosko. El punto de acceso y el kiosko deben pertenecer al mismo complejo y al mismo piso.

Dónde Entrar

Actividad Menú Qué se configura
Dar de alta o editar un punto de acceso Operación > Kioskos Institución, complejo, piso, nombre, descripción y estado activo.
Registrar o editar un kiosko Operación > Kioskos Dispositivo, token, punto de acceso, URL, nombre, descripción, polling, estado y colores.
Activar o desactivar registros Operación > Kioskos Tablas de Puntos de acceso y Kioskos, columna Acciones.

Alta de un Punto de Acceso

El punto de acceso identifica el lugar donde se encuentra el kiosko. Use nombres operativos claros, por ejemplo Lobby principal, Recepción urgencias o Entrada torre norte.

  1. Ingrese a la web administrativa de Control de acceso.
  2. En el menú lateral, abra Operación > Kioskos.
  3. En el formulario Crear punto de acceso, seleccione la Institución.
  4. Seleccione el Complejo. El sistema filtrará los pisos disponibles.
  5. Seleccione el Piso donde estará ubicado el kiosko.
  6. Capture el Nombre del punto de acceso.
  7. Capture una Descripción si necesita documentar la ubicación o alcance.
  8. Deje marcada la opción Activo.
  9. Presione Guardar.

Después de guardar, el punto aparece en la tabla Puntos de acceso con su nombre, complejo, piso, estado y acciones para editar, activar o desactivar.

Alta de un Kiosko

El kiosko es el dispositivo que abre la aplicación pública de autoservicio. Desde ahí el paciente puede buscar su cita del día o validar el token QR para registrar llegada.

  1. En Operación > Kioskos, ubique el formulario Crear kiosko.
  2. Seleccione Institución, Complejo y Piso.
  3. Seleccione el Punto de acceso. Solo se muestran puntos del complejo y piso seleccionados.
  4. Capture el Dispositivo. Debe ser único, por ejemplo kiosko-lobby-pb.
  5. Capture el Token. Al crear un kiosko es obligatorio y debe tener al menos 8 caracteres.
  6. Revise la URL de kiosko. El sistema la genera automáticamente con el código del dispositivo y el token capturado.
  7. Capture el Nombre, por ejemplo Kiosko lobby planta baja.
  8. Capture una Descripción si ayuda a soporte o mantenimiento.
  9. Configure Polling, que indica cada cuántos segundos el kiosko actualizará información. El valor permitido va de 2 a 30 segundos.
  10. Deje marcada la opción Activo.
  11. Presione Guardar.
Cuide el token: no lo publique en documentos visibles para pacientes. Si necesita cambiarlo, edite el kiosko y capture un nuevo token. Si está editando otros datos, puede dejar el campo token vacío para conservar el existente.

Después de guardar, el kiosko aparece en la tabla Kioskos con columnas de Dispositivo, Nombre, Punto, Polling, Estado y Acciones.

Configuración de Colores

La sección Colores define la presentación visual configurada para el kiosko y muestra una vista previa. Use combinaciones de alto contraste y consistentes con la identidad de la clínica.

Campo Uso Valor sugerido
Color fondo Color base del kiosko y de la vista previa. white para un fondo claro.
Color texto Color principal de lectura. black sobre fondo claro.
Color primario Color principal de identidad, botones o bordes destacados. royalblue para acciones principales.
Color acento Color de apoyo para estados, confirmaciones o énfasis visual. seagreen para confirmaciones.
Vista previa: el formulario muestra el nombre del kiosko y el texto Buscar cita. Valide ahí que el fondo, texto y color primario sean legibles antes de guardar.

Uso Operativo del Kiosko

Una vez configurado, abra la URL generada en el dispositivo físico. En operación diaria, el kiosko ofrece dos caminos:

  • Escanear QR: permite validar el token QR de una cita y registrar llegada.
  • Buscar cita: permite buscar citas del día por nombre y apellido, con celular o fecha de nacimiento como datos opcionales.

Cuando la llegada se registra correctamente, el kiosko muestra el resultado y el folio de turno correspondiente. Este folio es el que el paciente usará para identificar su llamado en pantalla.

Ejemplo Práctico

Objetivo

Configurar un kiosko para el lobby de planta baja de Clínicas Alfa, asociado al punto de acceso de recepción principal.

1. Crear el punto de acceso

  1. Ir a Operación > Kioskos.
  2. En Crear punto de acceso, seleccionar Institución: Clínicas Alfa.
  3. Seleccionar Complejo: Torre Central.
  4. Seleccionar Piso: Planta baja.
  5. Capturar Nombre: Lobby principal.
  6. Capturar Descripción: Punto de acceso para registro de llegada en recepción principal.
  7. Confirmar que Activo esté marcado y presionar Guardar.

2. Registrar el kiosko

  1. En Crear kiosko, seleccionar Institución: Clínicas Alfa.
  2. Seleccionar Complejo: Torre Central.
  3. Seleccionar Piso: Planta baja.
  4. Seleccionar Punto de acceso: Lobby principal.
  5. Capturar Dispositivo: kiosko-lobby-pb.
  6. Capturar Token: LobbyPB2026.
  7. Capturar Nombre: Kiosko lobby PB.
  8. Capturar Descripción: Kiosko de autoservicio para pacientes con cita de hoy.
  9. Dejar Polling: 5 segundos y Activo marcado.

3. Configurar colores

Color fondo white
Color texto black
Color primario royalblue
Color acento seagreen

Presionar Guardar. La URL generada será similar a /kiosk/?device=kiosko-lobby-pb&token=LobbyPB2026. Use el botón Abrir para probarla.

Verificación Final

  • El punto de acceso aparece como Activo en la tabla Puntos de acceso.
  • El kiosko aparece como Activo en la tabla Kioskos.
  • El kiosko está asociado al punto correcto y al mismo complejo y piso.
  • La URL de kiosko abre correctamente desde el botón Abrir.
  • La vista previa tiene contraste suficiente entre fondo, texto y color primario.
  • En el kiosko, la opción Buscar cita permite encontrar citas de hoy y registrar llegada.
  • En el kiosko, la opción Escanear QR permite validar el token QR cuando esté disponible.
Si el kiosko no funciona: confirme que el backend esté disponible, que el kiosko esté activo, que la URL use el código de dispositivo correcto y que el punto de acceso no haya sido desactivado.
