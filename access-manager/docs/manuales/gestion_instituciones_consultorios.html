Gestión de instituciones y consultorios

Guía administrativa para configurar la estructura física y operativa: instituciones, complejos, pisos, salas de espera y consultorios.

Resumen Rápido

Dirigido a Administradores de sistema y administradores de negocio.
Resultado Estructura institucional lista para operar citas, kioskos, consultorios y turnos.
Orden recomendado Institución, complejo, piso, sala de espera y consultorio.

Estos catálogos forman la base de operación del sistema. Una institución contiene uno o varios complejos; cada complejo contiene pisos; y dentro de los pisos se configuran salas de espera y consultorios. Si esta estructura está incompleta, las citas, kioskos, asignaciones y pantallas de turnos no podrán operar correctamente.

Secuencia recomendada: cree primero la institución, después sus complejos, luego los pisos y finalmente las áreas operativas como salas de espera y consultorios.

Instituciones

La institución representa a la organización principal que administra sedes o complejos. Es el primer registro que debe existir antes de crear edificios, pisos y consultorios.

  1. Abra Instituciones > Instituciones.
  2. Use el buscador para revisar si la institución ya existe por nombre o razón social.
  3. En Crear institución, capture Nombre.
  4. Capture Razón social si aplica.
  5. Use Notas para observaciones administrativas.
  6. Presione Guardar.

Para editar, seleccione la institución en la tabla. El formulario cambiará a Editar institución; modifique los datos y guarde. Puede usar Desactivar o Activar para controlar su uso sin borrar el registro.

Complejos

Un complejo representa una torre, edificio, sede o unidad operativa perteneciente a una institución. La zona horaria del complejo se usa para interpretar horarios de citas y ventanas de llegada.

  1. Abra Instituciones > Complejos.
  2. Si hay muchas instituciones, use Buscar institución o el filtro Todas las instituciones.
  3. En Crear complejo, seleccione la Institución.
  4. Capture Nombre.
  5. Capture Descripción, Dirección y Teléfono si están disponibles.
  6. Seleccione o capture la Zona horaria, por ejemplo America/Mexico_City.
  7. Deje marcada la opción Activo y presione Guardar.
Revise la zona horaria: una zona horaria incorrecta puede afectar horarios de citas, check-in y reportes operativos.

Para editar, seleccione un complejo en la tabla o use el botón Editar. Desde la columna Acciones también puede activar o desactivar el complejo.

Pisos

Los pisos son niveles físicos dentro de un complejo. Se usan para filtrar consultorios, salas de espera, kioskos, citas y reportes.

  1. Abra Instituciones > Pisos.
  2. Seleccione la Institución.
  3. Seleccione el Complejo. El sistema solo mostrará complejos de la institución seleccionada.
  4. Capture Número, por ejemplo PB, 1 o 2.
  5. Capture Nombre visible, por ejemplo Planta baja o Piso 2.
  6. Capture Descripción si ayuda a identificar el nivel.
  7. Deje marcada la opción Activo y presione Guardar.

Para editar, seleccione el renglón del piso en la tabla. El mismo formulario cambiará a Editar piso.

Salas de Espera

Las salas de espera representan áreas donde recepción, kiosko y operación pueden ubicar visitantes antes de pasar a consulta.

  1. Abra Instituciones > Salas de espera.
  2. Seleccione la Institución.
  3. Seleccione el Complejo.
  4. Seleccione el Piso.
  5. Capture Nombre, por ejemplo Sala principal.
  6. Capture Descripción si aplica.
  7. Capture Capacidad estimada si desea registrar una referencia operativa.
  8. Deje marcada la opción Activa y presione Guardar.

Para editar, seleccione la sala en la tabla. Puede activar o desactivar salas desde la columna Acciones.

Consultorios

Los consultorios son espacios físicos donde se asignan médicos, operadores y citas. También son el destino que puede mostrarse al llamar un turno.

  1. Abra Instituciones > Consultorios.
  2. Seleccione la Institución.
  3. Seleccione el Complejo.
  4. Seleccione el Piso.
  5. Capture Código, por ejemplo C-101 o CONS-12.
  6. Capture Nombre visible, por ejemplo Consultorio 101.
  7. Capture Instrucciones de acceso si el paciente o el personal necesita una referencia adicional.
  8. Seleccione uno o varios Clústers asociados al consultorio.
  9. Deje marcada la opción Activo y presione Guardar.
Clústers requeridos: el consultorio debe asociarse a al menos un clúster del mismo complejo y piso. Si se usarán pantallas de turnos, ese clúster debe tener una pantalla activa para que los llamados puedan mostrarse.

Para editar, seleccione el consultorio en la tabla o use Editar. Desde Acciones puede activar o desactivar el consultorio.

Ejemplo Práctico

Objetivo

Configurar una sede básica para Clínicas Alfa con una torre, un piso, una sala de espera y dos consultorios.

1. Crear la institución

  1. Ir a Instituciones > Instituciones.
  2. Capturar Nombre: Clínicas Alfa.
  3. Capturar Razón social: Clínicas Alfa S.A..
  4. Presionar Guardar.

2. Crear el complejo

  1. Ir a Instituciones > Complejos.
  2. Seleccionar Institución: Clínicas Alfa.
  3. Capturar Nombre: Torre Central.
  4. Capturar Zona horaria: America/Mexico_City.
  5. Presionar Guardar.

3. Crear piso y sala

  1. Ir a Instituciones > Pisos.
  2. Seleccionar Institución: Clínicas Alfa y Complejo: Torre Central.
  3. Capturar Número: PB y Nombre visible: Planta baja.
  4. Guardar y después abrir Instituciones > Salas de espera.
  5. Crear Sala principal en Torre Central, Planta baja, con capacidad estimada 30.

4. Crear consultorios

  1. Ir a Instituciones > Consultorios.
  2. Seleccionar Institución: Clínicas Alfa, Complejo: Torre Central y Piso: Planta baja.
  3. Crear consultorio con Código: C-101 y Nombre visible: Consultorio 101.
  4. Seleccionar el clúster correspondiente del piso y presionar Guardar.
  5. Repetir para Código: C-102 y Nombre visible: Consultorio 102.

Verificación Final

  • La institución aparece como activa.
  • El complejo pertenece a la institución correcta y tiene zona horaria válida.
  • Los pisos pertenecen al complejo correcto y tienen nombre visible claro.
  • Las salas de espera están activas y asignadas al piso correcto.
  • Los consultorios tienen código único, nombre visible y clúster asignado.
  • Los consultorios que recibirán citas están activos.
  • Los clústers asociados a consultorios con turnos tienen al menos una pantalla activa.
